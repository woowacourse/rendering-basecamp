# 0003. 상세 페이지에 OG 메타 태그 넣기

- 날짜: 2026-10-17
- 상태: 채택

## 맥락

PR 템플릿 5번에 따르면 `/detail/:id` 페이지에 OG 메타 태그가 달려 있어야 한다. 서버 HTML 템플릿에는 `<!--{OG_TAGS}-->` 자리만 있고 이 자리를 채우는 코드가 없었다. 그래서 상세 페이지 `<head>`에 주석이 그대로 남아 있었다. [0002](0002-상세-페이지-서버-렌더링.md)에서 상세 라우트가 이미 `movieDetail`을 받아 오므로 이 데이터로 태그를 만든다.

## 고려한 선택지

**태그를 만드는 방식**
- `renderToStaticMarkup`으로 `<meta>` JSX를 문자열로 바꾸기: 이미 쓰는 `react-dom/server`에 있다. `content` 속 따옴표·꺾쇠는 React가 이스케이프한다.
- 템플릿 문자열 + escape 함수: 기존 HTML 템플릿과 모양이 같다. 대신 escape 함수를 직접 만들어야 한다.

**넣을 태그**
- `og:title`·`og:description`·`og:image`: 미리보기 카드에 필요한 최소 구성이다.
- 위 3개 + `og:type`·`og:url`: `og:url`은 요청 host로 절대 URL을 만들어야 해서 코드가 는다.
- 위 3개 + `<title>`도 영화 제목으로 바꾸기

**`og:image`에 쓸 이미지**
- `poster_path`: 모달 포스터와 같은 이미지다. 세로형이다.
- `backdrop_path`: 가로형이라 미리보기 카드(1.91:1)에 더 잘 맞는다.

## 결정

`renderOgTags`가 `movieDetail`로 `og:title`·`og:description`·`og:image`를 `renderToStaticMarkup`으로 만든다. 이미지는 포스터(`original` 크기)를 쓴다. `renderPage`는 `<!--{OG_TAGS}-->` 자리를 이 결과로 채운다. 상세 정보가 없으면 빈 문자열을 넣고, 포스터가 없으면 `og:image`만 뺀다.

## 근거

- 제목·줄거리는 TMDB에서 받아 오는 데이터라 따옴표가 섞일 수 있다. 그러면 `content` 속성이 깨진다. `renderToStaticMarkup`을 쓰면 이스케이프를 직접 구현하지 않아도 된다.
- 요구 사항은 OG 태그를 확인하는 것이라 미리보기 카드에 필요한 3개만 넣었다.
- 포스터는 모달에 보이는 이미지와 같아서 화면과 맞는다.
- `replace`의 두 번째 인자로 문자열 대신 함수를 넘긴다. 문자열로 넘기면 `$&`, `$'` 같은 글자가 치환 패턴으로 해석돼 줄거리 내용이 바뀔 수 있다.
- 홈(`/`)이나 상세 조회에 실패한 경우에는 태그 없이 주석만 지운다.
